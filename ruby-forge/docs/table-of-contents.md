## Phases
Phases group related functionality, not calendar time. It is normal for the
last issue completed in a project to belong to phase 1.

- Phase 1 — the smelter ladder: separating mixed scrap by melting the lowest
  first, step by step, so nothing is burned that could be recovered.
- Phase 2 — corundum growth: a furnace that grows a single ruby crystal the
  size and shape of a gold bar.
- Phase 3 — ruby as a building material: ruby shaped like bricks, as single
  crystals or as sintered ruby ceramic (the stretch goal).

Every phase's deliverable is a blueprint a builder could work from.

## Project files
- .file-index-counter - the highest reading-order index used by any file in
  the project, so a new file can take the next number without a search.
- run-phase-demo - asks which completed phase to demonstrate, then runs it.
