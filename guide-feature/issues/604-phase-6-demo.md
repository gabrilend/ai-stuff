# 604 — Phase 6 demo: three viewers, one page

phase 6, viewers for the desk and the browser

## Intended behavior

`issues/completed/demos/phase-6-demo` replays a recorded history (or
attaches to the live system if it is up) and opens the terminal view, the
Lua window and the HTML page in Firefox together, takes a screenshot of each
at the same page number, and shows: pages drawn per viewer, delay from page
built to page drawn per viewer, and the three screenshots side by side.
