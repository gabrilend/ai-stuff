# 005-utf8 — info

Counting text in characters (UTF-8 code points), not bytes. The canvas reader
(102), the word finder (103) and the fit check (105) all measure rows through
here, so they cannot disagree about a row's length. LuaJIT has no `utf8`
library, so this is its own.

Text that is not valid UTF-8 is refused, with the byte where it went wrong:
a stray continuation byte, a cut sequence, an encoding longer than needed, a
surrogate half, or a code point past U+10FFFF (the ranges of RFC 3629).

| Name | Type | Meaning |
|---|---|---|
| `length(text)` | function | the number of characters, or nil and the bad byte's position |
| `split(text)` | function | the characters, one string each, or nil and the bad byte's position |
| `pad(text, width)` | function | spaces added up to `width` characters; longer text comes back as it is |

Characters, not terminal columns: some characters take two columns in a
terminal, and whether to count those is open question 4
(`docs/open-questions.md`). If it is answered "columns", it changes here.

Tests: `007-test-canvas-text.lua`, "characters".
