### Assistant Response 1

I'll measure the tracked files by extension the way GitHub's Linguist does
(bytes of tracked files), then see which directories hold the HTML.

GitHub's number is exact: the pushed tree holds 279 `.html` files totaling
16,029,915 bytes, which is byte-for-byte what the GitHub languages API reports
for HTML. Two things combine to make that 41%.

**The denominator is small.** Linguist only counts "programming" and "markup"
languages. Everything else in the repo is thrown out before the percentage is
computed: 143 MB of PNGs, 119 MB of PDFs, 94 MB of `.w3x` maps, and 74 MB of
Markdown (Markdown is classed as prose, not markup). What survives is about 38
MB, and HTML is 16 MB of it.

| Counted language | Bytes |
|---|---|
| HTML | 16,029,915 |
| Lua | 13,416,414 |
| C | 3,982,249 |
| Shell | 2,901,841 |
| Rust | 1,322,978 |
| everything else | ~275,000 |

**The HTML is concentrated in three places.**

| Location | Files | Bytes | Share of HTML |
|---|---|---|---|
| `neocities-modernization/archive/wordclouds/` | 11 | 8.17 MB | 51% |
| `hero-less-moba/docs/HTML/` | 159 | 5.18 MB | 32% |
| luasocket's luarocks test page, vendored 3 times (`libs/lua`, `raleigh3/horse/libs`, `handheld-office/scripts/fuzzy-computing/lib`) | 6 | 1.28 MB | 8% |
| `libs/Local LLM Inference Optimization_ The Complete Guide.html` (a saved web page) | 3 | 0.37 MB | 2% |
| `gif-generator/docs/` | 43 | 0.26 MB | 2% |

The wordclouds are generated output. Each is a menu page listing ~7,000 words as
individual anchor tags, about 1 MB apiece, and every regeneration was archived
with a timestamp, so five near-identical copies sit side by side.

**Why the docs folders don't get filtered.** Linguist's documentation rule is
`^[Dd]ocs?/`, anchored to the repo root. In a monorepo,
`hero-less-moba/docs/HTML/` doesn't match, so all 159 generated doc pages count
as source. Same for the vendored luarocks pages: Linguist excludes `vendor/` and
`node_modules/` but not `lib/` or `libs/`.

Note your local git status already has all of `hero-less-moba/docs/HTML/*.html`
staged for deletion, so the next push drops 5 MB of this on its own.

If you want the stats to reflect only hand-written code, a root `.gitattributes`
fixes it without deleting anything:

```

*/docs/HTML/** linguist-documentation
libs/** linguist-vendored
**/luarocks/** linguist-vendored
```
