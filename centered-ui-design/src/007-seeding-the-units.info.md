# 007-seeding-the-units

Scatters the first units from the seed (data generation). Same seed, same units, on every build.

| Offers | Takes | Gives |
|---|---|---|
| `new_stream(seed)`, `next_fraction(stream)` | | a 32-bit xorshift random stream; fractions in [0, 1) |
| `seed_units(front, count, seed, fold)` | record array | fills it: one in five a foe far out, the rest owned by the seat whose quarter they start in |
