# 024-the-map-from-beyond

The map seen from far beyond, straight down, unfolded: the flat map with every unit and cuboid as a dot in its color, repainted each frame for the arches' bands.

| `draw(picture, units, unit_count, cuboids, cuboid_count, tiers, colors)` | the front record arrays |
