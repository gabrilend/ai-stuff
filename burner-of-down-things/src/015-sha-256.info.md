# 015-sha-256.lua

SHA-256 (FIPS 180-4) in LuaJIT's 32-bit bit operations, no outside program.

| Function | In | Out |
|---|---|---|
| `of_string(text)` | string | 64 lower-case hex characters; refuses a non-string |
| `of_file(path)` | path | 64 hex characters; reads 64 KiB at a time, so a large file is never held whole |

Checked against the standard's vectors and against `sha256sum` at every size
near a block boundary (tests/022). Speed: see the phase 1 demo.
