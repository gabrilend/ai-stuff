# 118-the-switchboard-commands.lua

The switchboard's row in the command table (docs/012): `machine number`
prints `language model prompt <next free number>: <what is wanted>`, the
tag to write at the top of a parcel (117's `next_free`). Works on the
project, not a case, and records nothing — a number is recorded only when
a parcel first uses it (117's `accept`).
