# 041-director-test — proof for the director

`luajit src/041-director-test.lua [DIR]`. A stand-in director whose first
draft misspells a hue: the wall refuses it once, the corrected draft
renders to `now.gif` with no partial file left; the brief carries the prose
and the word list; a chat message gets a reply and a re-rendered, different
gif. Re-runs itself with `SAY_CLAUDE` set.
