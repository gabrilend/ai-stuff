# 042-say — the terminal front door

Run by the root `say` script: `luajit src/042-say.lua DIR RUN_DIR KEEP_DIR`.
The script makes `RUN_DIR` (`tmp/shared-memory/say/<run>/`) and
`KEEP_DIR` (`output/say/<run>/`) first.

In order: the box (type, finish with an empty line) → unknown words found
(`036`) and taught all at once (`038`), tracker updated → the viewer opened
in the background, watching `RUN_DIR/now.gif` → the director's first draft
(`040`) → the chat (`you>`; `/done` ends it) → the prose, score, gif and chat
log copied to `KEEP_DIR`, the viewer closed, `output/goodbye` written.

The code is loaded from beside this file; `DIR` is only where the words,
documents, tracker and output live. Stand-ins for tests: `SAY_CLAUDE`
(instead of `claude`) and `SAY_VIEWER` (instead of the viewer, which is
`delta-version/scripts/gif-viewer/view-gifs --watch=FILE` until issue 701a
moves it here).
