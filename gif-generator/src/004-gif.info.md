# 004-gif — the GIF89a encoder

Palette and index-rectangles in, complete looping .gif bytes out. No
external library; the format froze in 1989. Blocks in order: header,
screen descriptor, global color table, Netscape loop-forever, then
per frame a graphic control (delay in hundredths) + descriptor + LZW
data in 255-byte sub-blocks, then the trailer. Every frame fully
replaces the last; no transparency.

The LZW dictionary is flat (keyed by previous-code and next-byte, no
strings in the hot loop). Code width grows the moment the entry being
added needs more bits — checked before the add — because the decoder
runs one entry behind; the file's comments record the desync the
round-trip test caught when this was done in the other order.

## Usable surface

- **encode(spec) → byte string** — spec carries width, height,
  palette_bytes (the 768-byte table from the palette module), frames
  (list of width*height index arrays), delay_cs (whole hundredths of
  a second; fractions refused). A gif with no frames is refused.
- **write(path, spec) → byte count** — encode and land on disk;
  returns the honest measured size for reports.

Proof lives in the test file: an independent decoder round-trips
every frame byte-for-byte, and ImageMagick has read our output
independently. The final proof remains a browser looping the file.
