# 038-png — stills

Writes a still picture as a PNG with no compression library: stored
(uncompressed) deflate blocks, CRC-32 and Adler-32 worked by hand. The shape
films use it for `--still` and `--stills=`.

## Usable surface

- **encode(width, height, rgb) → bytes** — `rgb` is a string of
  width × height × 3 bytes, rows top to bottom; the result is a whole PNG
  file, 8-bit RGB, ready to write.
