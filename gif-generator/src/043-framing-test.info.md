# 043-framing-test — proof for a scene's promises about the picture

Walks every frame of every scene that makes a `framing`, `clearance` or
`spacing` promise, using the painter's own projection, and reports the
worst frame.

CLI: `luajit src/043-framing-test.lua DIR [scene-name ...]`. Run with the
rest of the shape films' checks by `./test-shape-films`.
