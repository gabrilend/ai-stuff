# Shape scene format

Generated by `src/051-shape-docs.lua` from `src/048-shape-words.lua`, the same lists
the wall (`src/049-shape-wall.lua`) checks every scene against. Edit those, then run
`luajit src/051-shape-docs.lua .`; never edit this file by hand.

A scene is data: a Lua file returning one table, read in an empty sandbox. A word not
listed for the place it stands is refused, with every other mistake in the scene, each
with the nearest legal word.

## World space

Positions are world units around the origin, `{ x, y, z }`: x to the right, y upward,
z toward the viewer of a still camera.

- A still camera (`camera = { distance, fov, tilt }`) sits `distance` back along +z (7
  when left out), looks at the origin, and is tipped down by `tilt` radians.
- A moving camera (`camera.motion`) has an eye and a target, both worked out each frame;
  it looks from the eye at the target, keeping its up near the world's up, and `roll`
  turns the picture about that line in radians.
- `fov` is the picture's width (and height, the picture being square) as an angle, in
  degrees; 45 when left out.
- Time is the loop: moments run from 0 up to 1, and every cycle, turn and frequency
  counts whole times round per loop, so the last frame leads into the first with no seam.
- Angles: `turns` count whole turns; `angle`, `center`, `amount` (of a rock) and `tilt`
  are radians; `phase` is a fraction of a cycle.

## Names

- Hues: `rose ember gold jade teal ice violet`, the gif generator's hue vocabulary, and `cloud`, white light.
- Shapes: `cone` `cube` `horn` `icosahedron` `octahedron` `star_prism` `superball` `terrain` `tetrahedron` `torus`.
- Styles: `glow` `solid` `wire`.
- Effects: `bleed_hue` `glow` `shatter` `swell`.
- Solids a superball morphs through: `cube` `icosahedron` `octahedron` `tetrahedron`.
- Route motions (the ones a rolling, becoming or anchored shape needs): `arc` `bezier` `conveyor` `keyframes` `spline` `wave`.
- Tags made without being written: `drop` `tie` `trackside` `trail`.

### `scene`

| Word | Takes | Meaning |
|------|-------|---------|
| `name` | a value | the film's name, which its GIF is named after |

| `strokes` | a list of stroke tables | thin lines of light bent into a travelling wave |

| `streaks` | a streaks table | speed lines rushing past a moving camera |
| `lights` | a list of light tables | point lights for blobs |
| `fluid` | a fluid table | a liquid in an invisible tilting box |
| `framing` | a framing table | a promise about how many tagged shapes stay in the picture |
| `clearance` | a list of clearance tables | a promise that the lens keeps clear of tagged shapes |
| `spacing` | a spacing table | a promise that tagged shapes keep apart |
