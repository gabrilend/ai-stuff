# 004-obj

OBJ and its .mtl colour library (issue 003). Parts per (o/g name, material). Faces of more than three corners become fans. Unread statements are counted in shape.skipped. Reads as y up.

| Offers | Takes | Gives |
|---|---|---|
| `read(bytes, name, read_neighbour)` | read_neighbour(file_name) returns a companion file's bytes or raises | a shape; raises with a line number on a missing corner or an undefined material |
| `read_materials(bytes, name)` | .mtl text | { material name = {r,g,b} } |
| `write(shape, made_by, mtl_file_name)` | | obj text, mtl text |
