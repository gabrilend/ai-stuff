# 003-stl

STL, text and binary (issue 002). Kinds are told apart by size, not by the word "solid". Stored normals are ignored. Reads as z up; writing a y-up shape turns it a quarter so it stands the same way.

| Offers | Takes | Gives |
|---|---|---|
| `read(bytes, name)` | the file as a string | a shape; text STL keeps one part per solid, binary gives one part |
| `is_binary(bytes)` | | true when size = 84 + 50 × count |
| `write_text(shape, made_by)` | | text STL, one solid per part; made_by follows the first solid's name |
| `write_binary(shape, made_by)` | | binary STL bytes; made_by in the 80-byte header |
