# crossing.lua (arena)

The crossing demo's map (issue 804), built from a few numbers: a 40×22
field, a dividing wall with a 12-cell gap, two 2×2 pillars each side, and
two armies 5 wide and 8 deep. Returns `cell` (1.0), `unit_radius` (0.4),
`unit_speed` (3.0 a second) and `rows` (text, "#" wall, "." ground, "w"/"e"
an army's starting cell).
