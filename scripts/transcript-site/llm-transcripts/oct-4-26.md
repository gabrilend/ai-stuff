made by hand. For each such commit it reads every file the commit touched, and
it does that without checking what kind of change each one was. The log shows
three kinds of path it can't read, and I checked each one against the azeroth
repository:

|---|---|---|---|

| **Added a submodule** (a pointer to another repository, not a file) | `modules-beta/mod-ale`, `mod-playerbots` | There's no file there, only the other repository's commit id. | **A real bug.** The change for a submodule is one added line, "Subproject commit 1ab53ba…", and the page shows that line as if you had written it. |
