# Pyrrhic Victory - Development Roadmap

This project focuses on design documentation and visual exploration. Implementation is secondary to conceptual clarity.

---

## Phase 1: Foundation Documents

Establish the core design through written documentation.

**Deliverables:**
- Core mechanics document (timeline system)
- Setting document (the Storm Castle)
- Enemy bestiary with behavior patterns
- Player progression flow

**Exit Criteria:**
Someone reading these documents can explain the game to another person.

---

## Phase 2: Visual Language

Develop the aesthetic identity through diagrams and concept sketches.

**Deliverables:**
- ASCII diagram of the causeway layout
- Timeline visualization (showing branching runs)
- Enemy silhouette studies
- Color palette reference sheet
- UI mockups for casualty counter

**Exit Criteria:**
The visual identity is distinct and consistent.

---

## Phase 3: System Diagrams

Map the game systems as flowcharts and state diagrams.

**Deliverables:**
- Player state machine (alive -> dead -> faded -> resumed)
- Enemy AI behavior trees
- Timeline management flowchart
- Victory condition logic diagram

**Exit Criteria:**
A programmer could implement the systems from these diagrams.

---

## Phase 4: Narrative Beats

Document the emotional arc and key moments.

**Deliverables:**
- First death script (the recording, the resurrection)
- First save script (preventing a past death)
- Festus encounter phases
- Victory sequence (both pyrrhic and true)

**Exit Criteria:**
The emotional journey is documented moment by moment.

---

## Phase 5: Prototype Specification

Create implementation-ready technical documents.

**Deliverables:**
- Entity component specifications
- Timeline data structure design
- Rendering requirements
- Audio cue list

**Exit Criteria:**
All systems are specified to implementation detail.

---

## Phase 6: Reference Collection

Gather visual and tonal references.

**Deliverables:**
- Mood board (existing media that captures the tone)
- Architectural references (gothic castle elements)
- Military references (WW2 equipment, uniforms)
- Horror references (Lovecraftian entities)

**Exit Criteria:**
Reference collection guides all visual work.

---

## Current Status

**Active Phase:** 1
**Progress:** Initial documentation in progress

---

## Notes

This roadmap prioritizes *understanding* over *building*. Each phase deepens comprehension of what this game is, what it feels like, what it means.

Build nothing until you know what you're building.
