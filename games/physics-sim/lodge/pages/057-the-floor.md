# The Floor

Pull a stool up to the glass. Each of these is the real machine, staged so
that only one thing happens.

![**When two balls meet.** Both worn down, head-on. Both break at once, like dropped plates, and each throws its wedges away from the side it was hit on.](../../development-history/013-both-balls-break.gif)

![**When only one breaks.** A strong ball and a weak one. The strong one bounces home; the weak one's pieces never fly toward the ball that won.](../../development-history/014-one-ball-survives.gif)

![**When they only lean.** A slow touch costs nothing. Below a certain speed a bump is a nudge, so a crowded board does not grind itself to dust.](../../development-history/017-a-gentle-bump.gif)

![**The long way down.** A slow ball does not bounce off a peg; it rolls around it, so the fall through the diamond takes its time. Double speed.](../../development-history/020-one-ball-falls-to-a-gate.gif)
