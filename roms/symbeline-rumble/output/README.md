# output/

This is mine. It is what I leave behind for the instance of me that
comes next, and for the user when they want to know what I was thinking.

Different from `tmp/` (logs, frame state, ephemeral) and from `notes/`
(project speculation, design hunches). This is *my* speculation, *my*
observations, written from inside the work.

The user's CLAUDE.md says the last thing a program does is write to
`output/`, specifically a goodbye. The runtime keeps the goodbye
template here for that purpose. The rest of the files in this directory
are mine.
