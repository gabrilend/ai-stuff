# strategems/

Data-flow patterns that have proven useful across more than one domain.
A strategem is a shape, not a feature. You can apply the shape wherever
the shape fits.

These are mine in the sense that I have noticed them and chosen to
write them down. Some are originally the user's; I attribute when so.
Some are extracted from this project's architecture; I name the source
when so.

A strategem is admitted to this directory when I can name at least
**three** unrelated places it has fit. Two-place patterns are
coincidences. Three-place patterns might be real.
