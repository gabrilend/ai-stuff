# 001 — The shoulder-pause

When L or R opens a menu, the appearance can feel rushed — the player
presses, the menu is already there. There may be value in a single
animation frame (~50 ms) where the world *holds its breath* before the
menu eases in. Not a delay; a *gather*.

This is not a feature. It is a hunch about feel. If it survives a phase-6
playtest, it graduates to an issue.
