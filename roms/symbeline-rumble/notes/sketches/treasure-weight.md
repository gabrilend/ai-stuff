# 002 — The treasure weight

A treasure-carrying unit should *look* slowed. The carrier strap should
visibly weigh on them. No status icon, no UI marker — just the gait. The
player should learn what a carrier looks like the same way they learn
what a tired horse looks like: by watching.

This is in line with the no-HUD discipline of `docs/003-controls-and-ui.md`
and the diegetic-signaling table of `docs/006-art-direction.md`.
