# 014-the-monorepo-and-the-page

Covers issues 105 and 106.

- Directory names become map names; titles with quotes and backslashes are
  quoted and read back unchanged.
- A small queue: a stack wires up, a pull request on a branch nobody has open
  is not blocked, a project waits on every pull request touching it, root
  files belong to `repository-root`, a question holds up its project; the map
  is valid and the same input writes the same bytes; the bottom of the stack
  tops the board and reaches the two above it and both projects.
- Refusals: two directories with one map name, a malformed snapshot line, a
  question with no project.
- **Generated files against their generators**: the committed monorepo map,
  its board and both example pages are regenerated and compared byte for byte.
- The page: HTML5, no script, no event handlers, every link lands, every box
  has a place, a waiting port says what it waits on, what a map says is
  escaped.
