§ 031-engine.h

src/engine/031-engine.h — generated by scripts/generate-info from the file's own comments; edit those, not this.

everything outside the engine may call (phase 2).

General description: a program is a set of stations — placements of boxes, which are ordinary C functions — with wires from each station's exits to other stations' input ports. There is one rule: a station runs when, and only when, every one of its input ports holds a value. Every run is a task on a ring the cores share, so a program is concurrent from its first line without anybody asking for threads.

Three operations build a program — place, configure, wire — and there is no fourth "start": writing the static values that feed the first stations is what sets it going (issue 212).

The words, since they are easy to confuse: box the code: a C function, its parameter sizes, its name. station one placement of a box: its own ports, exits, and error slot. port one input of one station: ring (a stream, consumed one value per run), static (a dial, read by every run), or none (never holds a value; the station cannot run). exit where one station's output goes: a list of {station, port}. task one run of one station, carrying copies of its inputs.

§ What it declares

§ engine_kind_extra_ports

int engine_kind_extra_ports(int kind)

The comparator and weighted kinds carry one more port than their box has parameters: the threshold, or the weights. It sits after the box's own ports, is only ever static, and is never handed to the box.

§ engine_error_text

const char *engine_error_text(int error)

§ engine_init

void engine_init(int cores)

Set up memory, the task ring and the station table for cores cores. Called once, on one core or the twin's main thread, before any core is started.

§ engine_core_main

void engine_core_main(int core)

What every core runs, from platform_start_cores: per-core setup, wait at the starting gate, then the run loop forever (on the twin: until engine_shutdown).

§ engine_open_gate

void engine_open_gate(void)

Open the starting gate. Nothing runs before this. Programs may be built before it (they begin at the gate) or after it (they begin at once).

§ engine_shutdown

void engine_shutdown(void)

Twin only in practice: ask every core to leave its run loop after the task it is running. A device never ends.

§ engine_is_idle

int engine_is_idle(void)

Every core asleep, the ring empty, no timer due and nobody building: nothing will happen until something outside acts. On the device this is "the user has not pressed anything yet", never "finished"; the twin's tests use it to know when a program has settled.

§ engine_place

int32_t engine_place(const struct box *box, const char *name, int kind, int n_exits)

Make a station running box. name is copied and kept, so an error message and a written-out program can say which station they mean. n_exits is how many exits the kind needs (1 for plain). Answers the new station's index, or a negative error. Every port starts as NONE.

§ engine_place_at

int32_t engine_place_at(int32_t index, const struct box *box, const char *name, int kind, int n_exits)

The same, into one particular place — which must be free and fully reclaimed. Refused loudly otherwise (issue 207, step 8).

§ engine_configure

int engine_configure(int32_t station, int port, int tag, const void *value, size_t size)

Give a port a source. For PORT_STATIC, value is the port's size in bytes and becomes the dial's setting; writing a static runs the readiness check, so this is also how a program is started.

§ engine_wire

int engine_wire(int32_t station, int exit, const struct destination *to, int count)

Replace one exit's destinations with this whole list, at once (issue 207: arrows are drawn in batches so every destination starts from the same instant). An empty list unwires the exit.

§ engine_port_fed

int engine_port_fed(int32_t station, int port)

Does any wire, from any station, feed this port?

§ engine_port_reserve

int engine_port_reserve(int32_t station, int port, int cells)

Grow a port now so it holds at least cells values at once.

§ engine_deliver

int engine_deliver(int32_t station, int port, const void *value, size_t size)

Push one value into a port from outside any box, exactly as a wire would: into a cell for a ring port, over the dial for a static one.

§ engine_remove

int engine_remove(int32_t station)

Take a station out of existence and give its place back (issue 207).

§ engine_mark_argument

int engine_mark_argument(int32_t station, int port, int door)

Doors (issue 309). Mark a port as the program's argument N, or an exit as its result N (-1 clears the mark). A marked port that no wire feeds is where the outside delivers that argument; a marked exit with nothing wired beyond it holds its values for whoever takes them, instead of discarding them.

§ engine_take_result

int engine_take_result(int32_t station, int exit, void *out, size_t size)

Take one held result out of a marked exit: 1 if taken, 0 if none is waiting, or a negative error.

§ engine_sweep

void engine_sweep(void)

Free whatever retired things no core can still be inside. The engine does this itself on every rewire and removal; this is for a caller that wants a removed place back sooner.

§ engine_timer

int engine_timer(int32_t station, int port, const void *value, size_t size, uint64_t first_ns, uint64_t period_ns)

Deliver value into a port at first_ns on the platform clock, and then every period_ns after (0: once). This is how "something is scheduled to arrive" is known when every core is idle — the 60 Hz input frame of phase 5 is one of these. Answers a timer number or an error.

§ engine_refuse

void engine_refuse(uint64_t detail)

"Not this value." The box's return is thrown away, the refusal is recorded in the station's error slot, and the station takes itself out of service by setting its inputs to none (issue 214).

§ engine_current_station

int32_t engine_current_station(void)

Which station is running on this core right now, or -1.

§ engine_random

uint64_t engine_random(void)

64 random bits from this core's own stream (seeded once from the platform). Per-core state, so a box asking for randomness breaks no rule about boxes remembering.
