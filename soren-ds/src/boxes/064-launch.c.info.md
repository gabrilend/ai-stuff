General description: saying a number, reading the clock, drawing a
random number, refusing on purpose, and stopping everything on purpose.

A source is a box with a trigger. A box with no inputs is always ready
and can never be made to run, because there is no port anybody can
write to — so every source here takes one input it ignores. Writing
that input is what asks for a reading. And that is why the clock is a
box rather than a wire: a value is never fresh at the instant it is
used, so a box that needs "now" asks for it inside itself.

There is no timer box. When every core has run out of work the idle
path already sleeps until the next scheduled delivery (issue 206); a
tick is the engine waking up and writing a port.

## What it offers

### say_number

```c
void say_number(int64_t value)
```

One line out the developer's channel: the station's own name, then the
number. The label comes from the engine telling the box which station
it is running as (issue 310's first open question, answered that way:
a second label input on every use was the other choice).

### echo

```c
int64_t echo(int64_t value)
```

Says the number, as say_number does, and passes it on unchanged — for
putting a report *on* a path rather than beside it. A report fanned out
beside a loop runs at the same time as the loop's next step, so its
lines can come out of order; one on the loop's own path cannot (found
building the counting scene of issue 312).

### clock

```c
uint64_t clock(int64_t trigger)
```

Nanoseconds on the platform clock, read inside the box.

### random_number

```c
uint64_t random_number(int64_t trigger)
```

64 random bits — the machine's natural width, narrowed by whoever needs
less (issue 310's second open question).

### refuse

```c
void refuse(int64_t value)
```

Always refuses, so the path a broken box takes (issue 214) always has
something to prove itself against. The value refused is the detail.

### stop_everything

```c
void stop_everything(int64_t value)
```

Stops the machine on purpose, so the panic path has the same.
