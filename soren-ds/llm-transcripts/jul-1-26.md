## What it is


A bare-metal handheld operating system for the **Anbernic RG DS** — a
dual-touchscreen ARM device (Rockchip RK3568 SoC) with D-pad + triggers left,

## The central architectural bet


The system is two layers with a hard waterline:


- **Below:** a small C kernel that does *only* what a kernel must — hardware bring-up, boot/exception vectors, the threading core's atomic primitives, the page allocator, and the lowest register pokes. That's the whole C surface.

- **Above:** *everything else* — drivers, compositor, filesystem, the four apps — is a **soramech map**: a dataflow graph of "boxes" wired together. The kernel doesn't know what an app is; it knows threads and wires. Leaf boxes (register pokes, atomics) are statically-linked C; the maps that wire them are JSON the runtime reads at boot and hot-swaps. The bet is paid for once in Phase 2 (the threading core must be excellent) and pays a dividend every phase after.


Apps have **no switcher and no back button** — they link to each other like
boxes calling boxes, each exposing named typed exits; round trips are just two
forward links. Text input is a **radial-menu chord** (D-pad direction × face
button = 32 chars/mode, triggers switch modes).

## 2. Project Purpose &amp; Goals


**Soren DS** is a custom bare-metal operating system for the **Anbernic RG DS** handheld device, built from scratch without running the stock OS. The vision centers on:


- **Four launch apps**: A soramech-based programming language, a dual-pane text editor, a pictochat-style messenger (with image attachments), and a paint program.

- **Novel UI paradigm**: Apps link to each other (no back button, no history stack), drawers slide in from screen edges when center buttons are pressed, and input is done via an 8-directional radial menu.

- **Multithreaded runtime**: The entire OS above C is a **soramech map** — a functional dataflow system where applications are composed as interconnected "boxes" that fire and communicate through wires.

- **5th app (post-launch)**: The Modeller — on-device 3D vertex-grid editing with dynamic model merging, demonstrating that the platform can host complex user-written apps.
