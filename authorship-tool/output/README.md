# Output Directory

This directory contains files generated by the Authorship Tool.

## What Gets Written Here

The Authorship Tool will write various outputs to this directory:

### Generated Content
- **Worksheets/Quizzes** - Questions for you to answer about your story
- **Analysis Reports** - Style analysis, relationship maps, gap identification
- **Integration Suggestions** - Recommended ways to incorporate your answers
- **Character Profiles** - Extracted character information
- **Object Catalogs** - Lists of important items and their appearances
- **Relationship Graphs** - Visual or text representations of connections

### Generated Media
- **Images** - Generated visuals for described objects and scenes
- **Poetry** - Character-focused poems (when enabled)

## Organization

Outputs are typically organized by type and date:
```
output/
├── worksheets/
│   └── 2026-01-08-chapter1-worksheet.txt
├── analysis/
│   └── 2026-01-08-style-report.txt
├── images/
│   └── amulet-of-echoes.png
└── integration/
    └── 2026-01-08-suggested-edits.txt
```

## Version Control

You may want to version control this directory to track:
- How your understanding of your story evolves
- Which questions the tool has asked over time
- Your answers and how they influenced your writing

Alternatively, you can treat this as temporary/generated content and exclude it
from version control (.gitignore).
