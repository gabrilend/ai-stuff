# Issue 8-048: Flatten Media Directory Structure for Neocities Deployment

## Priority
High

## Current Behavior

Media attachments are stored in a deeply nested Mastodon-style directory structure:

```
input/media_attachments/files/112/500/670/521/387/992/original/ad3a0a69d3dcf172.png
input/media_attachments/files/113/375/953/621/305/252/original/305cb9fa4ef3b2dc.png
...
```

HTML references use this nested path structure:
```html
<img src="/similar-different/media_attachments/files/112/500/670/521/387/992/original/ad3a0a69d3dcf172.png" ...>
```

**Problems with current structure:**
- Neocities and many hosting platforms struggle with deeply nested directories
- Manual upload is tedious (must recreate 7+ levels of nested folders)
- Bulk upload tools may fail or timeout on deep structures
- Total size: ~639 MB across many nested directories

## Intended Behavior

Media files should be stored in a flat directory structure:

```
output/media/ad3a0a69d3dcf172.png
output/media/305cb9fa4ef3b2dc.png
...
```

HTML references should use the simplified path:
```html
<img src="/similar-different/media/ad3a0a69d3dcf172.png" ...>
```

**Benefits:**
- Single directory to upload to Neocities
- Filenames are already unique (Mastodon uses content-addressable hashes)
- Simpler URL structure
- Easier to manage and verify uploads

## Technical Analysis

### Filename Uniqueness Verification

The filenames (e.g., `ad3a0a69d3dcf172.png`) appear to be content-addressable hashes generated by Mastodon. Need to verify there are no collisions:

```bash
# Check for duplicate filenames
find input/media_attachments -type f -exec basename {} \; | sort | uniq -d
```

If duplicates exist, a collision-resolution strategy is needed (e.g., prepend directory hash).

## Suggested Implementation Steps

### Phase 1: Verify Filename Uniqueness

1. **Scan all media files and extract basenames**:
   ```bash
   find input/media_attachments -type f -exec basename {} \; > /tmp/media-basenames.txt
   ```

2. **Check for duplicates**:
   ```bash
   sort /tmp/media-basenames.txt | uniq -d
   ```

3. **If duplicates exist**, design collision resolution:
   - Option A: Prepend parent directory hash (e.g., `387992_ad3a0a69d3dcf172.png`)
   - Option B: Use full path hash as prefix
   - Option C: Content-hash the file itself (most robust but slowest)

### Phase 2: Create Media Flattening Script

1. **Create `scripts/flatten-media`**:
   - Input: `input/media_attachments/files/...`
   - Output: `output/media/`
   - Copy files, renaming if collisions detected
   - Generate mapping file: `output/media/path-mapping.json`
     ```json
     {
       "/files/112/500/.../ad3a0a69d3dcf172.png": "ad3a0a69d3dcf172.png",
       ...
     }
     ```

2. **Script should be idempotent**:
   - Skip files that already exist in output
   - Only copy new/changed files

### Phase 3: Update HTML Generator

1. **Modify `render_attachment_images()` in `flat-html-generator.lua`**:
   - Change path construction from nested to flat
   - Local mode: `file:///...neocities-modernization/output/media/{basename}`
   - Production: `/similar-different/media/{basename}`

2. **Extract basename from attachment.url**:
   ```lua
   local basename = attachment.url:match("([^/]+)$")
   local img_src = media_base_path .. "/" .. basename
   ```

### Phase 4: Update URL Converter

1. **Modify `scripts/convert-urls`** URL_PATTERNS:
   ```lua
   {
       local_path = "file:///home/ritz/programming/ai-stuff/neocities-modernization/output/media",
       production_path = "/similar-different/media"
   }
   ```

2. **Remove old nested media pattern** (no longer needed)

### Phase 5: Integrate Into Pipeline

1. **Add to `run.sh`** (or create deployment script):
   ```bash
   # Flatten media before HTML generation
   ./scripts/flatten-media
   ```

2. **Ensure ordering**:
   - Media flattening must complete before HTML generation
   - HTML generation uses flat paths
   - URL conversion runs after HTML generation

### Phase 6: Testing

1. **Verify all images render locally**:
   ```bash
   # Count images in output
   grep -r "<img" output/*.html | wc -l

   # Check that all referenced images exist
   grep -oh 'src="[^"]*media/[^"]*"' output/*.html | \
     sed 's/src="file:\/\/\([^"]*\)"/\1/' | \
     while read path; do [ -f "$path" ] || echo "MISSING: $path"; done
   ```

2. **Verify production URLs**:
   ```bash
   ./scripts/convert-urls --to-production --dry-run
   ```

3. **Test upload to Neocities** (manual or via API)
