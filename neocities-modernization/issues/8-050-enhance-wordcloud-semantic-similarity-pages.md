# Issue 8-050: Enhance Word-Cloud Semantic Similarity Pages

## Priority
High

## Current Behavior

The word-cloud similarity pages (`output/wordcloud/{word}.html`) generated by `src/generate-word-pages.lua` have several limitations:

1. **Progress bars use per-poem colors**: Each poem's progress bar is colored by that poem's individual semantic color (from `poem_colors.json`). This creates a visually chaotic page with no unifying color identity for the word being explored.

2. **Similarity ranking ignores color context**: Poems are ranked purely by cosine similarity to the word embedding. The semantic color of the word is not factored into the ranking, so a "red-feeling" word might show poems that are semantically related but visually belong to entirely different color clusters.

3. **Poems-per-page is hardcoded**: `CONFIG.poems_per_word_page = 50` in `generate-word-pages.lua:109` — not configurable via `run.sh` or the TUI.

4. **No centroid-based chronological entry point**: The page has a generic "Back to Word Cloud" and "Chronological" link but no smart link that takes the user to the most representative chronological position for the word's poem cluster.

## Intended Behavior

Each word-cloud similarity page should:

1. **Compute the word's semantic color** and use it for page identity (header, title)
2. **Select poems via balanced color round-robin**, ensuring equal representation of all 7 semantic colors while maintaining word relevance — prevents monoculture where the word's color dominates
3. **Show colorful progress bars** — fix the current bug where bars appear gray, and display each poem's own semantic color to reveal the balanced selection's diversity
4. **Show a configurable number of poems** per page (defined via `run.sh` with `--wordcloud-poems-per-page N`)
5. **Include a centroid chronological link** at the top that navigates to the chronological poem most similar to the centroid embedding of all poems shown on that word page

## Design Rationale

### Why unify the page color?

The word-cloud is an exploration tool. When a user clicks "silence", they enter a themed world. A unified color (say, blue) reinforces the thematic cohesion — "these poems all feel blue, like silence." Per-poem colors fragment that experience and make the page feel like a random sample rather than a curated collection.

### Why factor color into ranking?

Without color context, the ranking is purely lexical-semantic. Two poems might be equally "about silence" but one is melancholy-blue and the other is rage-red. By weighting the ranking toward the word's own semantic color, we create a more thematically coherent set — the poems not only mention or relate to "silence" but they *feel* like the same kind of silence.

### Why a centroid chronological link?

The centroid of the selected poems represents the "average meaning" of the word's poem cluster. Finding the chronological poem closest to this centroid gives the user a single entry point into the timeline that best represents the thematic center of what they're exploring. It answers: "If I wanted to read through the collection starting from where this word lives, where would I begin?"
