# Phase 1 Progress: Foundation

## Goal
Establish the Love2D application skeleton with a navigable tile grid,
camera system, input handling, and coordinate conversion utilities.

## Completion Criteria
- Love2D window opens and runs the game loop.
- A tile grid renders and can be panned/zoomed.
- Mouse clicks resolve to tile coordinates.
- Input routing supports grid mode with vim-style keybinds.
- Phase 1 demo script in `issues/completed/demos/` shows the grid
  with camera navigation and coordinate display.

## Notes
- Phase 1 has no external dependencies beyond Love2D.
- All issues must be completed before Phase 2 (Factories) begins.
