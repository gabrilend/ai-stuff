# backwards-reader — table of contents

A program that reads text against its own grain, at several sizes at once,
and sets each turned-around version beside its original so the two can be
compared.

Source files and issue files are not listed here — the source order is
generated by `scripts/source-order.sh`, and the issues are indexed by
`docs/roadmap.md`.

## Where to start reading

**To understand what this is:** `notes/vision`, then
`docs/architecture.md`.

**To understand how it works:** `docs/datapath-the-ladder.md`. Everything
else hangs off the ladder.

**To build on it:** `docs/roadmap.md`, then the issue files for the phase
you are in.

**To find a pattern worth stealing:** `strategems/`.
