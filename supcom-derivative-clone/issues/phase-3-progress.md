# Phase 3 Progress — Inflows and Outflows

**The goal:** the economy. Territory pays mass; engineers on a four-button menu
raise energy that is lost with the ground it stands on; construction streams
resources into lines the player did not design; every line's output follows a
pattern drawn once; losing ground hurts the roster and spends the thorns.

**Ends with:** a match that plays itself — two bots placing factories and drawing
patterns — in which one side takes ground, the other side's roster goes to the
infirmary, and the report says which dune decided it.
