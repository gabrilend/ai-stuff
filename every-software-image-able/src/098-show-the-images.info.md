# 098-show-the-images — info

One recipe, every board the project describes, built. The phase 5 demo's numbers.

The claim phase 5 makes is that supporting a new computer is a new description file and no code at all. A paragraph saying so proves nothing. This builds the same seed for every machine described, side by side, and shows what came out -- and uses the phase 1 measurement to say what each of those images would actually be able to think with, which is what those two phases together are for.
