## What is here

Reference images gathered while working out what the first challenge monster looks
like. The setting's visual language is an open question — see
[the map draws itself](../issues/702-the-map-draws-itself.md) — and these are the
answer somebody found rather than an answer somebody wrote.

these as all rights reserved to Myke and seek permission before publishing them
onward or deriving art from them.

Nothing in the program reads this directory. It is here to be looked at while
drawing, and no build step, test, or documentation page depends on it.
