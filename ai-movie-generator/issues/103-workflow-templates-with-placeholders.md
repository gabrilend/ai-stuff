# 103 — workflow templates with placeholders

phase 1, the image call and the run

**Depends on:** 102

## Current behavior

The ComfyUI workflows folder is empty; no graph loads Dreamshaper-8.

## Intended behavior

Three API-format workflow graphs in `assets/workflows/`: text-to-image, image-to-image, and text-to-image with a controlnet — each loading models/diffusers/Dreamshaper-8 and using placeholders (`__PROMPT__`, `__NEGATIVE__`, `__SEED__`, `__WIDTH__`, `__HEIGHT__`, `__STEPS__`, `__CFG__`, `__INIT_IMAGE__`, `__STRENGTH__`, `__CONTROL_IMAGE__`, `__CONTROL_MODEL__`, `__CONTROL_WEIGHT__`). A dispatch table maps a request's shape to its template. The graphs are generated by a Lua tool from a node description, not hand-saved from the editor, so they can be regenerated when ComfyUI's node names change.

## Suggested implementation steps

1. Query ComfyUI's `/object_info` for the exact node names (diffusers loader, KSampler, VAE encode/decode, ControlNet apply).
2. The template generator.
3. Placeholder filling, failing on any placeholder left unfilled.
